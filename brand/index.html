11 · Tokens

Cómo se usan

Dos capas. Los tokens base (--pt-color-brand-orange) guardan valores. Los semánticos (--pt-accent, --pt-text-muted) dicen para qué sirven y cambian con el tema: los componentes usan solo los semánticos.

<link rel="stylesheet" href="/brand/tokens/tokens.css">

.boton {
  background: var(--pt-accent);
  color: var(--pt-on-accent);
  border-radius: var(--pt-radius-pill);
  height: var(--pt-layout-control-height);
}

<section data-theme="dark"> … </section>   /* tema oscuro por bloque */

// Tailwind
module.exports = { presets: [require('./brand/tokens/tailwind.preset.js')] }
